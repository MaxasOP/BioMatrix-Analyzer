# BioMatrix Analyzer

BioMatrix AI is a Next.js bioinformatics platform for sequence analysis, mutation detection, and AI explanations.

## Repository layout
- `web/` - Next.js + Supabase + Gemini bioinformatics platform
- `DNA Sample/` - Sample FASTA/text inputs

## Web app
```bash
cd web
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Environment variables and Supabase setup are documented in [web/README.md](web/README.md).
